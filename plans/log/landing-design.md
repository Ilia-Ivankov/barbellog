# Редизайн лендинга Barbellog

## Результат

- Обновлён публичный лендинг `/` в светлом редакционном стиле с типографикой Manrope и Playfair Display, фирменным красным `#f20d35`, графитовым цветом и логотипом Barbellog.
- Первый экран представляет дневник тренировок и фото жима штанги. Раздел библиотеки показывает карточки «Жим штанги» и «Упражнение лучник» с фотографиями.
- Добавлен блок демонстрации приложения со скриншотами дневника и статистики, а также финальный призыв к действию и футер.
- На узких экранах контент перестраивается в одну колонку; изображения сохраняют пропорции или используют управляемое кадрирование.

## Поведение и ограничения

- Вход ведёт на `/login`, CTA — на `/register`; при активной сессии действия открывают `/app`.
- Новые маршруты и API не добавлялись. Скриншоты демо отображаются как статические изображения без изменений.

## Проверка

- `npm run build` — успешно; TypeScript и production-сборка Vite завершились без ошибок.
- `npm run lint` — успешно.
- Проверены в реализации обе фотографии упражнений, оба демо-скриншота, логотип и условия переходов для пользователя с сессией и без неё.
- Визуальный предпросмотр через локальный браузер недоступен в текущей среде: браузер не подключился к Vite, а локальный HTTP-запрос заблокирован правами доступа к сокету. Стили для узкой, промежуточной и широкой ширины добавлены, но живой визуальный осмотр не подтверждён.
