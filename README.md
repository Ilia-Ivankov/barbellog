# Barbellog

Barbellog — учебный дневник силовых тренировок. В нём можно записывать тренировки и подходы, вести список упражнений и смотреть статистику.

> **Учебный проект.** Barbellog создан только для демонстрации и обучения. Это не готовый сервис для повседневного использования. Не сохраняйте в нём важные или конфиденциальные данные.

## Что нужно установить

Инструкция ниже рассчитана на Windows и PowerShell.

1. Установите Node.js версии **22.13 или новее** с [официального сайта Node.js](https://nodejs.org/en/download/). Выберите версию **LTS** и установщик для Windows с расширением `.msi`. Установщик также установит npm — программу, которая загружает зависимости проекта. Дополнительные инструкции доступны в [руководстве npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm/).
2. Закройте и заново откройте PowerShell. Проверьте, что Node.js и npm установлены:

   ```powershell
   node -v
   npm -v
   ```

Команда `node -v` должна показать версию не ниже `v22.13.0`.

Для просмотра приложения используйте браузер, например Microsoft Edge. Устанавливать отдельно SQLite, React, Vite или Express не нужно. SQLite входит в Node.js, а остальные библиотеки проект установит сам. Для первой установки зависимостей требуется подключение к интернету.

## Как запустить проект

Сначала распакуйте полученную папку или архив проекта. Откройте PowerShell в папке `barbellog` — там должен находиться файл `package.json`.

Установите зависимости бэкенда и фронтенда. Выполняйте команды по порядку:

```powershell
cd backend/barbellog-backend
npm ci
cd ../../frontend/barbellog-frontend
npm ci
cd ../..
```

Запустите приложение из корневой папки проекта:

```powershell
npm run dev
```

Команда автоматически подготовит локальную базу данных, а затем запустит API и сайт. Откройте `http://localhost:5173`. API работает по адресу `http://localhost:3000`. Если сервис неожиданно завершится, launcher выведет его код завершения или сигнал.

Не закрывайте окно PowerShell, пока используете приложение. Чтобы остановить сайт и API, нажмите `Ctrl+C` в этом окне.

## Как устроен проект

```text
Браузер → фронтенд → API → файл базы данных
```

- **Фронтенд** — страница приложения, которую вы видите в браузере. Он построен на React и запускается с помощью Vite.
- **API** — серверная часть на Express. Она принимает запросы от сайта и обрабатывает данные.
- **База данных** — локальный файл SQLite. Отдельный сервер базы данных устанавливать не нужно.

## Если не получается запустить

- Если PowerShell не находит `node` или `npm`, установите Node.js, затем закройте и заново откройте окно PowerShell.
- Если версия Node.js ниже `v22.13.0`, установите более новую версию с сайта Node.js.
- Если `npm ci` завершилась ошибкой, проверьте подключение к интернету и повторите команду в папке нужной части проекта.
- Если сайт или API не запускаются, проверьте, кто занимает порты `5173` и `3000`:

  ```powershell
  Get-NetTCPConnection -State Listen -LocalPort 5173,3000 |
    Select-Object LocalAddress, LocalPort, OwningProcess
  Get-Process -Id <PID>
  ```

  Завершайте процесс только если узнали в нём старый экземпляр Barbellog/Vite или API, затем повторите `npm run dev`. Не завершайте неизвестные процессы. Vite настроен на порт `5173` и остановится с ошибкой, если порт занят; другой порт не используется, потому что API разрешает origin `http://localhost:5173`.
- Если launcher сообщает, что API завершился, сохраните указанную причину — код завершения или сигнал. Она помогает отличить занятой порт от ошибки запуска или завершения процесса.
